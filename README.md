# Digitale Baustelle - Offline App

Dies ist eine **Progressive Web App (PWA)** für die digitale Baustellendokumentation.
Sie ist optimiert für den **Offline-Einsatz** auf Mobilgeräten (iOS/Android).

## Funktionen

*   🌐 **Komplett Offline:** Funktioniert ohne Internetverbindung.
*   📱 **App-Feeling:** Kann auf dem Homescreen installiert werden.
*   📐 **Funktionen:**
    *   Belastungsversuche
    *   Drehmoment-Messungen
    *   Auszugsversuche
    *   Automatische Protokoll-Erstellung (PDF-Druck)
    *   Foto-Dokumentation
    *   GPS-Erfassung

## Installation (iPhone/iPad)

1.  Öffne die Webseite in **Safari**.
2.  Tippe unten auf den **Teilen-Button** (Viereck mit Pfeil nach oben).
3.  Wähle im Menü **"Zum Home-Bildschirm"**.
4.  Tippe oben rechts auf **"Hinzufügen"**.

Jetzt hast du eine App auf dem Homescreen, die auch im Flugmodus funktioniert.
